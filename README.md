# MessOS
A Personal web OS made for Hackclub with draggable windows and apps, inspired by the old interface of Microsoft Windows 98.

<img width="1467" height="790" alt="Screenshot 2026-10-10 at 2 08 14 PM" src="https://github.com/user-attachments/assets/bf6b7f2b-beda-4ade-acc4-c6bd606a5f7c" />

# Demo this project: https://rockysmart1.github.io/MessOS/

Features:
- Welcome page
- Notes app: Write simple text
- Clock and date
- Draggable windows and apps
- Ability to open and close apps
